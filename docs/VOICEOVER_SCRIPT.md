## How to use this

Each scene gives a timecode, the duration, what is on screen at that moment,
and the line to speak. Word counts assume roughly **2.5 words per second**,
which is a clear, unhurried pace.

**If you are translating:** Hindi, Marathi and Gujarati typically run
**10–20% longer** than English for the same meaning. Every scene below has a
little silence at the end so a longer translation still fits. If a line still
runs over, shorten the *middle* of the sentence rather than the ending — the
ending is what lands.

The script deliberately avoids idioms, wordplay and long clauses, so it
translates cleanly.

# Please read before recording

**Two things in this video are not final, and the narration must not claim
otherwise.**

**1. The product photographs are placeholders.** Every product shows a green
striped box reading "Photograph required" with a filename. This is deliberate
— it shows exactly which photograph is needed and where it will sit. Nothing
in the script above claims these are real photographs.

If you would rather the client did not see placeholders at all, get their
photographs first and I will rebuild the video. If you show it as it is, say
so plainly at the start — for example:

> "The product photographs are not added yet. Those green boxes show where
> each photograph will appear once you send them to us."

**2. The map on the Contact page** shows a placeholder panel instead of a live
Google map, because the recording was made without internet access. The real
site shows a working map.

**Everything else in the video is real.** The products, the categories, the
filtering, the search and the WhatsApp message are all generated by the actual
website code — the WhatsApp message in Scene 17 comes from the same function
that will run on the live site.
